# MAKSIM Portfolio — версия 4

Светлое многостраничное портфолио с кастомным курсором, текстовой лупой, анимациями появления, параллаксом, магнитными кнопками и адаптивной версткой.

Для просмотра откройте `index.html`. Для публикации загрузите все файлы и папку `assets` на хостинг, сохранив структуру.


## Изменения версии 5
- Возвращена прежняя композиция архива проектов.
- Возвращена светлая верхняя часть футера с прежним текстом.
- Из hero-блока главной страницы удалено изображение, композиция переразложена.

## Версия 6
- Блок «Избранные концепты» возвращён к композиции версии 3.
- Исправлена сетка секции «05 / Объём концепта» во всех кейсах.
- Панель типа, года, роли и фокуса закреплена при прокрутке на десктопе.


## Версия 7
- Стоимость во всех разделах изменена на «по договорённости».
- В контактах уточнено, что актуальное портфолио — на этом сайте, а профиль на Kwork используется для связи.

## Версия 8
- Содержание обновлено под актуальный опыт: фриланс с 2024 года, Tilda, WordPress, HTML/CSS/JS/PHP, админ‑панели, базы данных, отправка заявок на почту и в Telegram.
- Обновлены главная, «Услуги», «Обо мне», «Контакты» и подписи в мобильном меню. Стоимость по‑прежнему «по договорённости», почасовая ставка на сайте не указана.
