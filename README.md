# MAKSIM — premium architectural portfolio

Многостраничное портфолио в светлой архитектурной стилистике. Версия переработана под более высокий коммерческий уровень: сильный арт‑дирекшн, единая модульная сетка, выразительная типографика и аккуратные микровзаимодействия. Сайт работает без сборщика на чистых HTML, CSS и JavaScript.

## Страницы
- `index.html` — главная
- `projects.html` — архив проектов
- `project-clinic.html`, `project-estate.html`, `project-ai.html` — отдельные страницы кейсов
- `services.html` — услуги и стоимость
- `about.html` — об авторе и принципах работы
- `contact.html` — контактная страница и короткий бриф
- `privacy.html` — политика конфиденциальности

## Что переработано
- новый первый экран с крупной типографикой и проектом внутри композиции;
- журнальная чередующаяся сетка избранных работ;
- единый визуальный язык для всех внутренних страниц;
- стартовая стоимость изменена на `30 000 ₽`;
- новый набор шрифтов Manrope + Cormorant Garamond;
- премиальные hover‑состояния, переходы страниц и деликатный параллакс;
- адаптивная версия для планшетов и телефонов.

## Кастомный курсор
- обычное минималистичное состояние;
- расширенное круглое состояние на ссылках;
- отдельный квадратный курсор со стрелкой на кнопках;
- трансформация курсора в лупу непосредственно в точке наведения;
- лупа включается только на мелком неинтерактивном тексте до 15 px;
- на кнопках, ссылках, заголовках, изображениях и формах лупа не появляется;
- на сенсорных устройствах кастомный курсор полностью отключён.

## Публикация
Загрузите содержимое папки на хостинг, сохранив папку `assets`. Главная страница должна называться `index.html`.

## Перед публикацией
1. Проверьте ссылку на профиль Kwork.
2. Замените демонстрационные кейсы и тексты реальными материалами.
3. Добавьте юридические и контактные данные в политику конфиденциальности.
4. Для загрузки Manrope и Cormorant Garamond нужен доступ к Google Fonts; при его отсутствии используются системные шрифты.
