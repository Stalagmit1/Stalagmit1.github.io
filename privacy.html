1. Общие положения

Настоящая политика описывает общие принципы обработки информации, которую посетитель добровольно передаёт при обращении к владельцу сайта.

2. Какие данные могут обрабатываться

Имя, контактные данные, содержание сообщения, сведения о проекте и техническая информация, необходимая для корректной работы сайта.

3. Для чего используются данные

Чтобы ответить на обращение, уточнить задачу, подготовить предложение, вести деловую переписку и обеспечить стабильную работу сайта.

4. Передача данных сторонним сервисам

Для связи и оформления заказа используется Kwork. При переходе на эту площадку обработка данных регулируется документами соответствующего сервиса.

5. Срок хранения

Данные хранятся только в объёме и в течение срока, необходимых для коммуникации и исполнения договорённостей, если иной срок не установлен законом.

6. Контактные данные владельца

Перед публичным запуском сайта владельцу необходимо добавить в этот раздел актуальные юридические и контактные сведения.
